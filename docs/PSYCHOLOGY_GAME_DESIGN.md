# Pypet Psychology, Motivation & Learning Design

## Purpose
Pypet uses psychology to make learning enjoyable, confidence-building, sustainable, and mastery-oriented. Psychology is used to support the learner, never to manipulate or pressure them.

## Required game pillars
All pillars are required for overall progression: School/curriculum, pet care, World exploration, Python practice, projects, social/collaborative opportunities where available, trophies/milestones, job readiness, and wellbeing/confidence activities.

## Motivation model
1. Autonomy: let players choose appearance, pet lineage, practice order within unlocked material, activities, projects, and cosmetic rewards while preserving required mastery gates.
2. Competence: provide clear goals, immediate understandable feedback, progressive difficulty, retries, debugging help, mastery checks, and visible skill growth.
3. Relatedness: use supportive pet reactions, mentors/teachers, cooperative challenges where appropriate, and positive recognition rather than humiliation or public failure.
4. Purpose: continually connect Python skills to visible changes in the pet, town, projects, and eventual job-ready portfolio.

## Learning loop
Every lesson: Learn -> See -> Write -> Run -> Inspect -> Debug -> Practice -> Challenge -> Apply -> Reflect -> Master.

Lessons are cumulative. Each new lesson builds on the learner's persistent project and prior mastered skills. Practice and debugging count as pet learning and contribute to trophies/rewards, but cannot bypass mastery gates.

## Motivation pacing
Break the broad curriculum into many short milestones. Each milestone should provide a meaningful celebration, trophy/badge progress, pet-learning progress, coins/cosmetics or World unlocks, and a preview of the next goal. Avoid reward overload; rewards should reinforce learning rather than replace it.

Use multiple reward horizons:
- Immediate: feedback, pet reaction, small learning XP.
- Session: completed lesson/challenge reward.
- Short-term: module milestone/trophy.
- Medium-term: World/pet/evolution unlock.
- Long-term: portfolio project, graduation, job-readiness certification and rare lineage opportunities.

Avoid mandatory streak loss, punitive energy systems, shame language, manipulative timers, or fear-of-missing-out mechanics. A missed day should not erase progress.

## Confidence and mental wellbeing
Use growth-oriented language: mistakes are expected data for debugging. Celebrate effort plus strategy, not empty praise. Give learners control to retry, slow down, review prerequisites, or request hints. Include calm spaces, positive pet interactions, reflection, accomplishment history, and reduced-motion/audio controls.

Never present the game as medical or mental-health treatment. Wellbeing features are supportive game design only.

## Cognitive load
Introduce one major concept at a time, connect it to prior knowledge, show concrete examples before abstraction, provide worked examples and fading hints, and use retrieval/review before large jumps. Revisit concepts in later projects so knowledge is durable.

## Accessibility and sensory safety
No intentional strobing, rapid flashing, screen shake, or high-frequency visual effects. Motion and audio must be independently controllable. Provide readable contrast, scalable UI, clear interaction affordances, and non-audio alternatives for important feedback.

## World design
The World should provide a strong sense of place: recognizable buildings, interiors, rooms, yards, paths, environmental landmarks, pet-scale objects, weather/ambient variation without unsafe flashing, and meaningful interactions. School is a required location and a central progression hub, not a menu pasted onto the World.

## Mastery and assessment
Mastery must be demonstrated through doing, not merely reading or receiving rewards. Use varied checks: code writing, prediction, debugging, modification, explanation, and applied projects. Allow repeated attempts with adaptive hints. Advanced learners can accelerate through demonstrated competence but still encounter all required domains.

## Evidence basis
The design is informed by systematic reviews finding that well-designed gamification can support motivation and learning, while effects can weaken when novelty and extrinsic rewards dominate. Therefore Pypet prioritizes competence, meaningful application, autonomy, cumulative mastery and intrinsic purpose over leaderboards or endless points.
