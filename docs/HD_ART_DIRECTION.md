# Pypet HD Art Direction

## Target
Pypet should ship with cohesive high-definition game art rather than placeholder emoji/utility UI. Temporary emoji are functional fallbacks only.

## Asset families
- Unique egg illustrations for every lineage and rarity.
- Baby/young/evolved/rare/mythic pet illustrations for every lineage.
- World background and location scenes: Home, School, Hatchery, Market, Park, Clinic, Habitats, Trophy Hall, Wilds, Workshop/Lab and Treasure Trove.
- Food illustrations and item icons.
- School characters, classroom props and Python-learning game pieces.
- Evolution celebration artwork.
- World construction/development artwork unlocked through Python progression.

## Presentation
Use a cheerful polished virtual-pet aesthetic, readable silhouettes, expressive faces, high-quality lighting and consistent perspective. Keep visual effects gentle and avoid strobing, flashing, rapid flicker and screen shake.

## Audio pairing
Each location gets a compatible musical loop and gentle sound palette. The default home/world tune should be happy and inviting. Pet reactions should have short, soft sounds. Evolution celebrations should be celebratory without sudden loud or rapidly repeating effects.

## Accessibility
All animation and audio systems must provide reduced-motion/mute controls. Avoid visual patterns that could create flashing/strobe effects.

## Implementation strategy
Keep functional UI and game logic independent from art assets so HD illustrations can replace placeholders without changing game rules. Use density-appropriate Android resources and compressed formats suitable for mobile delivery.
