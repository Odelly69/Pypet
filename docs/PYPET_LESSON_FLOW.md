# Pypet Hands-On Lesson Flow

Every structured lesson uses the same player-facing learning loop. The goal is complete understanding and independent ability, not merely reading or answering quizzes.

## Required stages

1. **Learn** — concise explanation, vocabulary, syntax, and why the concept matters.
2. **See** — a concrete working example in Python and, where useful, an animation or pet/world demonstration.
3. **Write** — the learner writes the code. Copy-only completion does not count as mastery.
4. **Run** — execute the code and see the real output/behavior.
5. **Inspect** — compare output, state, and behavior with the goal.
6. **Debug** — diagnose and repair an intentional mistake or the learner's own error.
7. **Practice** — complete a second guided exercise with progressively less scaffolding.
8. **Challenge** — solve a fresh problem independently.
9. **Apply** — use the concept in the Pypet World, pet behavior, automation, graphics, or a project.
10. **Reflect** — explain what was learned, what failed, and why the final solution works.
11. **Master** — demonstrate competency in a final check before progression is awarded.

## Rules

- A lesson may not be marked complete by opening it or reading the explanation.
- Incorrect attempts are safe: the learner receives feedback, keeps progress, and can retry.
- Help can be requested without punishment; hints progressively reveal less code.
- The pet learns alongside the player. Successful mastery contributes to the active pet's education/evolution progression.
- Core lessons remain free and are never ad-gated.
- Advanced lessons may include a project/capstone stage after Mastery.
- Graphics lessons must include visual feedback; coordinate/resolution lessons must let the learner work with multiple screen sizes; Pygame/Tkinter lessons must require actual code interaction.
- Job-readiness lessons add professional artifacts such as tests, documentation, Git workflows, code review, portfolio work, and interview simulations.

## Example

A variables lesson is not `read -> quiz -> done`.

It is:

`Learn variables -> See a pet-health example -> Write variables -> Run -> Inspect values -> Debug a broken assignment -> Practice -> Challenge -> Apply variables to a pet routine -> Reflect -> Master.`
